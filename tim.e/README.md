# CALIBRE T-65 · 陀飞轮机芯拆解视图

一只虚构的手动上链陀飞轮腕表机芯的可交互 3D 拆解模型。单 HTML 文件、全程序化生成（几何 / 贴图 / 声音零外部素材）、离线可跑——双击即用，无需网络。

> Fan-made technical demo for educational purposes.
> Not affiliated with, endorsed by, or representing any watch brand.
> Contains inlined [Three.js r161](https://threejs.org/) — MIT License, © three.js authors.

## 运行

- 直接双击 `index.html`（Chrome / Edge），无网络依赖。
- 建议用最新版浏览器；移动端 ≤900px 会自动收纳控件。

## 规格（数字即法律）

| 参数 | 值 |
|---|---|
| 机芯 | φ30.0 mm · 厚 5.2 mm · 手动上链 |
| 摆频 | 21,600 vph（3 Hz，每秒 6 拍） |
| 摆幅 | A = 240° + 45°·√P（P = 剩余动力），满链 285° |
| 擒纵 | 瑞士杠杆式，15 齿，30 拍/转，锁值 2.5° |
| 传动比 | 条盒 84/12 → 中心轮（1 r/h）→ 三轮 → 四轮（1 r/min）→ 擒纵轮（12 r/min） |
| 动力储存 | 65 h（扭矩 M(P) = 6.5 + 3.0·P mN·m） |
| 陀飞轮框架 | 1 r/min，偏心 6 时位 |
| 宝石 / 螺丝 | 25 颗红宝石 · 18 颗烧蓝螺丝 |
| 零件 | 30 个可交互零件，≈230 总零件 |

## 技术要点

- **零外部资源**：Three.js r161 以 UMD 形式内嵌，所有几何、贴图（日内瓦纹 / perlage / 表盘）、音效（WebAudio 脉冲串 tick + 棘轮咔哒）均程序化生成。
- **真实运动学**：摆轮相位、擒纵轮角度、轮系转速全部由齿数比与拍数推导，非贴图动画。
- **状态分享**：全部状态（机位 / 爆炸 / 透视 / 着色 / 分步 / 导览 / 选中）编码进 URL hash，0.7s 静默同步，带 hash 打开直接还原。
- **画质三档**：高 = MSAA 4× + Bloom + 阴影；低档自动降级（FPS < 38 降档，只降不升）。

## 已知取舍

- SSAO 未实现（高档画质用 MSAA + Bloom + 阴影代替）。
- 声音离线渲染下载（WAV 导出）未实现，实时播放完整。
- 慢放档下框架默认跟随减速，可用「框架跟随」开关切回 1 r/min。
- 代码经过压缩（为内嵌 Three.js），可读性一般；如需二次开发可让 AI 反格式化。
