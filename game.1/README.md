# 方块寻宝岛 🏝️⛏️

> 一个单文件的类我的世界体素沙盒小游戏：48×48 程序化生成的随机小岛，
> 挖掘 / 建造 / 寻宝。三渲二像素风，**零外部依赖**——Three.js 已完整打包，
> 断网、手机、微信内置浏览器都能玩。

## 🎮 玩法

岛的地下某处埋着 **8 块黄金**，全部挖出来即胜利（计时结算）。

| 平台 | 操作 |
| --- | --- |
| 电脑 | WASD 移动 · 空格跳 · 左键按住挖 · 右键放置 · 滚轮 / 1-6 选方块 |
| 手机 | 左下摇杆移动 · 右侧滑动转视角 · 「挖」长按挖掘 ·「放」放置 ·「跳」跳跃 |

挖掉的方块自动进背包，可以随时放回去盖房子。

## ✨ 特点

- 每次打开都是**随机生成的新岛**：丘陵、湖泊、沙滩、树林
- 7 种方块：草 / 泥土 / 石头 / 沙 / 木头 / 树叶 / 水；挖掘有裂纹进度反馈
- 水里有浮力，可以游泳；掉出世界会自动送回出生点
- 挖掘 / 放置 / 捡到金块 / 胜利均有 WebAudio 合成音效
- 方块全部实例化渲染 + 实时阴影，桌面 60 FPS

## 🚀 运行 / 部署

双击 `index.html` 即玩；上传 GitHub Pages 时放到仓库根目录即可
（Settings → Pages → Deploy from a branch → main / root）。
